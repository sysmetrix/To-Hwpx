서비스로 돌아가기이용약관오픈소스·글꼴 고지

개인정보처리방침

시행일: 2026년 7월 12일

원본 문서와 생성된 HWPX는 변환 서버에 업로드하지 않습니다. 변환은 사용자의 브라우저 메모리에서 수행됩니다.

1. 처리하는 정보

구분정보처리 시점
문서 변환선택한 문서 내용, 파일명, 생성 HWPX사용자 기기의 브라우저 메모리에서만 처리하며 운영 서버로 전송하지 않음
익명 사용 통계페이지 경로, 브라우저·기기 유형, 국가 수준 위치, 변환 형식·성공/실패 같은 사용 이벤트사용자가 통계 수집에 동의한 경우에만 PostHog로 전송
호스팅 로그IP 주소, 요청 시각, 요청 URL, 사용자 에이전트 등 통상적인 접속 로그Vercel 또는 GitHub Pages에 접속할 때 호스팅 사업자가 처리할 수 있음

분석 이벤트에는 문서 본문, 파일명, 붙여넣은 텍스트, 생성 HWPX 바이트를 포함하지 않습니다.

2. 외부 요청과 국외 처리

  • PostHog(미국 리전): 사용자가 동의한 익명 사용 통계. 동의를 거부하거나 철회할 수 있습니다.
  • Markdown 이미지 서버: 문서에 원격 이미지 주소가 있을 때 해당 주소로 직접 요청합니다. 요청 상대방은 IP 주소 등 접속 정보를 확인할 수 있습니다.
  • HWP5 엔진: HWP5 입력을 처리할 때 같은 서비스 도메인에 고정된 @rhwp/core 코드와 WASM을 불러옵니다.
  • rhwp 외부 뷰어: 사용자가 별도 확인한 경우에만 iframe을 로드하고 생성된 HWPX 바이트를 전달합니다.

3. 보유와 파기

  • 문서와 변환 결과는 페이지 메모리에서만 유지하며, 파일을 제거하거나 페이지를 닫으면 참조와 임시 URL을 해제합니다.
  • 분석 동의 상태와 화면 설정은 브라우저 localStorage에 저장되며 사용자가 사이트 데이터를 삭제하면 함께 삭제됩니다.
  • 익명 분석 정보의 운영 목표 보유기간은 90일입니다. 정식 운영 전 PostHog 프로젝트의 보유기간 설정을 동일하게 확인합니다.
  • 호스팅 로그의 보유기간은 각 호스팅 사업자의 정책을 따릅니다.

4. 동의 거부와 철회

통계 수집을 거부해도 문서 변환 기능을 사용할 수 있습니다. 서비스의 ‘지원 환경 → 로컬 처리’ 화면에서 언제든지 동의 또는 거부 상태를 변경할 수 있습니다. 철회 후에는 새로운 분석 이벤트를 전송하지 않습니다.

5. 안전조치

핵심 라이브러리를 고정 버전으로 자체 호스팅하고, 콘텐츠 보안 정책, 입력 크기 제한, 안전하지 않은 URL 차단, HWPX 구조 검증을 적용합니다. 정밀 미리보기는 별도 동의 전에는 외부 뷰어를 로드하지 않습니다.
